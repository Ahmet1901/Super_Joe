# Super Joe

Super Joe, Unity oyun motoru kullanılarak geliştirilmiş bir 2D platform oyunudur. 

> **Not:** Bu proje, üniversitedeki **Oyun Programlama** dersi kapsamında bir eğitim/dönem projesi olarak geliştirilmiştir.

## Proje Hakkında
"Super Joe", engelleri aşıp (testereler, tuzaklar ve düşmanlar) altınları toplayarak bölümleri geçmeye çalıştığınız klasik 2D platform dinamiklerine sahiptir. Proje içerisinde animasyonlar, basit düşman davranışları, toplanabilir nesneler ve bölüm geçiş mekanikleri gibi temel oyun geliştirme pratikleri barındırmaktadır.

## Özellikler
- Temel 2D Platform Mekanikleri (Hareket, zıplama vb.)
- Çeşitli Düşmanlar ve Tuzaklar (Hareketli testereler vb.)
- Skor / Altın toplama sistemi
- Seviye (Level) geçişleri ve oyun sonu dinamikleri
- 2D animasyonlar ve tilemap tabanlı bölüm tasarımları

## Kurulum
1. Repoyu bilgisayarınıza klonlayın veya indirin:
   ```bash
   git clone https://github.com/Ahmet1901/demo2.git
   ```
2. Unity Hub'ı açın ve "Add" butonuna tıklayarak bu projenin klasörünü seçin.
3. Projeyi Unity editörü ile açın.
4. `Assets/Scenes` klasörü içerisindeki ana sahneyi (Scene) açarak oyunu Play modunda test edebilirsiniz.
